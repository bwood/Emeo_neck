Emeo Neck

# Motivation

Better-fitting and more ergonomic neck alternatives for the Emeo electronic saxophone.

## The neck pieces

I printed these using Generic PLA. 

If you turn the cap upside down it shouldn't need supports.

The necks will need supports under their discs. Then bent one obiviously needs a support at the end.

## The flex rings

I printed these using Generic TPU and an Engineering Plate. 

Set the infill to 8% or so to make these flexible. This is your neck cork.  If you have trouble pulling these on to the necks, heat them up with a hair dryer or heat gun. It takes some force to get them on, but the snug fit is worth it.
